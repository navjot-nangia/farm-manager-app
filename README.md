# Farm Manager

A mobile-first progressive web app for turning a crop planting date into a simple field-management timeline.

## MVP features

- Add fields with crop, variety, acres, location, and planting date
- Generate stage-based crop planning milestones
- Daily and upcoming task views
- Complete tasks and export individual reminders to a calendar
- On-device storage, offline support, and PWA installation
- Starter templates for cotton, soybean, corn, sorghum, and wheat

## Run locally

Serve the repository over HTTP, for example:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Important

This MVP provides planning prompts, not pesticide, fertilizer, or irrigation prescriptions. All field decisions must be checked against current product labels, local Extension guidance, field observations, and applicable regulations.
